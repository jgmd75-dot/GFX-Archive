Plugins here may need the shared `.jsfx-inc` files from GFX-II beside them to run.

- `gfx-g-loop.jsfx` — GFX G Loop (archived 9 Oct 2026). Needs gfx-drift, gfx-output, gfx-ui, gfx-panel and gfx-instrument from GFX-II.
